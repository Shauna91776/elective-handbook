# Epic 00 – Environment Setup & Project Foundation

## Epic Overview

Before building any software, I need a stable and organised development environment.

This epic focuses on creating the tools, repositories, documentation and workflow that will support every project completed during the elective preparation.

There is intentionally very little coding in this epic.

The goal is to eliminate setup problems so that future sprints can focus on learning and development.

---

# Why This Epic Matters

Many software projects lose time because developers constantly fix their environment instead of building features.

By completing this epic first I will:

- Have a repeatable workflow
- Understand how my work is organised
- Track progress professionally
- Begin building a consistent GitHub commit history
- Reduce future setup issues

---

# Learning Objectives

By the end of this epic I should be able to explain:

- What GitHub Projects are
- What GitHub Issues are
- Why documentation matters
- How my repositories are organised
- How the handbook supports my learning
- How my workflow mirrors a real software development team

---

# Success Criteria

This epic is complete when:

- Every required repository exists.
- GitHub Project is configured.
- Handbook repository has its initial structure.
- Development tools are installed and working.
- HealthSafe is ready for Spring Boot development.
